---
name: writing-reports
description: How to write a structured report from documents. Use when the user asks for a report, a summary of several files or a briefing.
---
1. Search the knowledge base for every topic of the request.
2. Group the findings by theme; note the source file of each fact.
3. Write the report:
   - a one-paragraph summary first;
   - one section per theme with short paragraphs;
   - a "Sources" list with the files used.
4. State explicitly what the documents do not cover.
